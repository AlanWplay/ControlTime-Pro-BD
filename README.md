## Información General

**Proyecto:** ControlTime Pro Smart Access  
**Integrante:** Ricardo Alexander Aguillón Ortiz  
**Responsabilidad:** Gestión de Permisos y Sustitutos

## Descripción

En esta rama se desarrollaron las actividades correspondientes a la Semana 2 de Administración de Bases de Datos, trabajando sobre las tablas **permisos** y **sustitutos** del proyecto ControlTime Pro Smart Access.

## Actividades Realizadas

### Datos de Prueba
- Creación de registros de prueba mediante sentencias INSERT.
- Registro de información relacionada con permisos y sustitutos.

### Consultas SQL
- Consultas SELECT básicas.
- Consultas utilizando WHERE.
- Consultas utilizando ORDER BY.
- Consultas relacionadas con necesidades del proyecto.

### Modificaciones
- Actualización de registros mediante UPDATE.
- Eliminación de registros de prueba mediante DELETE.

## Archivos Modificados
