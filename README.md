## Descripción del Proyecto

Repositorio utilizado para el desarrollo de las actividades de la Semana 2 del proyecto ControlTime Pro Smart Access. En este repositorio se almacenan los scripts SQL, consultas, datos de prueba y evidencias relacionadas con la base de datos del sistema.

### Datos de Prueba
- Inserción de registros mediante sentencias INSERT.
- Validación de información almacenada en la base de datos.
- Pruebas de funcionamiento de las tablas asignadas a cada integrante.

### Consultas SQL
- Consultas SELECT.
- Consultas con cláusulas WHERE.
- Consultas con ORDER BY.
- Consultas relacionadas con los requerimientos del sistema.

### Modificaciones de Datos
- Actualización de registros mediante UPDATE.
- Eliminación de registros mediante DELETE.
- Verificación de integridad de la información.

## Archivos del Repositorio

### 01_estructura_tablas.sql
Contiene la estructura de las tablas de la base de datos.

### 02_datos_prueba.sql
Contiene los registros de prueba utilizados para verificar el funcionamiento de la base de datos.

### 03_consultas.sql
Contiene consultas SELECT, UPDATE, DELETE y consultas específicas del proyecto.

### 04_seguridad.sql
Contiene configuraciones y sentencias relacionadas con la seguridad de la base de datos.
